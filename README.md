## 設計方針

ページの**上半分は子どもの領域、下半分は大人の領域**として完全に分けている。

**子ども側（ファーストビュー）**
- 巨大な絵文字カードだけ。文字が読めなくても、どれを押せば何が起きるか分かる
- カードは押したら必ず音が鳴る。**まだ中身が無い「つぎは なにかな」カードも、押せば揺れて音が鳴る**（無反応にすると4歳は壊れたと思う）
- 外部へ出るリンクをこのエリアに置かない

**大人側（スクロールした先）**
- 安全面の明示（広告・課金・通信・データ保存先）を最初に置く。親が最初に不安になるのはここ
- 各ゲームの対象年齢・所要時間・失敗の有無
- ホーム画面追加、アクセスガイド、図鑑リセットなど運用のコツ

## しくみ

- **単一HTML・外部依存ゼロ**。フォントもJSライブラリも読み込まない
- 背景のグラデーションは `body::before` の `position: fixed` レイヤー。iOS Safari は `background-attachment: fixed` が効かないため
- ヘッダーの虹はインラインSVG（絵文字の🌈はAppleフォントだと四分の一円弧に見えて切れて見えるため、アイコンと揃えて自前で描いている）
- カードのタップ音は Web Audio でその場で合成

## ゲームを増やすとき

`index.html` の `<main class="grid">` の中の `<a class="card">` を1つコピーして、絵文字・名前・URLを差し替えるだけ。グリッドは `auto-fit` なので枚数に応じて自動で段組みが変わる。あわせて「おうちのかたへ」に `<h3>` セクションを1つ足す。

## アセットの作り方

外部ツールを使わず macOS 標準の `qlmanage` + `sips` で生成している。

```bash
qlmanage -t -s 1024 -o . icon.svg      # SVG → PNG
sips -Z 512 icon.svg.png --out icon-512.png
```

OGP画像（1200×630）は、`qlmanage` が**非正方形のSVGを正方形キャンバスに収めようとして拡大・ずれを起こす**ため、SVG側を 1200×1200 で作り、中央630pxのバンドにデザインを置いて `sips -c 630 1200` で切り出している。

> iOSのアイコンはURL単位で強くキャッシュされる。差し替えるときは**ファイル名ごと変える**こと。
